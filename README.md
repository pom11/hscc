# HSCC — Hermes Spark Cluster Control

**Private installation package for managing a DGX Spark GPU cluster with AI agents.**

## What is HSCC?

HSCC is the operational backbone for managing a cluster of DGX Spark nodes running AI models via vLLM and orchestrated by Hermes agents. It replaces the HSCCCC macOS app with a Hermes-native CLI.

## Quick Start

```bash
# Initialize (detects existing setup, wires components, deploys model)
hscc init

# Check status
hscc status

# Chat with agents
hscc chat

# Manage cluster
hscc cluster start   # Start model
hscc cluster stop    # Stop model
hscc cluster status  # Show status
```

## Installation

```bash
# Clone this repo (private)
git clone <private-repo-url> ~/.hscc
cd ~/.hscc

# Install hscc CLI
pip install -e ./install/hscc-cli/

# Run initialization
hscc init
```

## Components

- `hscc-daemon` — Monitoring daemon with watchdog
- `hscc-chat` — WebSocket gateway client
- `hscc-agent-coordinator` — Agent lifecycle + worktrees
- `hscc-governance` — Policy engine + permissions
- `hscc-skills` — Skills & templates installer
- `hscc-provision` — Model management
- `hscc-cluster` — Cluster operations
- `hscc-events` — Event bus
- `hscc-orchestrator` — Agent dispatch
- `hscc-projects` — Project management
- `hscc-bootstrap` — Bootstrap command
- `hscc-optimizations` — Performance tuning

## Configuration

Config is stored at `~/.hscc/config.yaml` (auto-generated by `hscc init`).

Secrets are NOT stored in config. Use:
- SSH agent for cluster authentication
- Hermes device.json for gateway auth

## Troubleshooting

```bash
# Check health
hscc status

# Reset config (keeps plugins)
hscc reset

# View daemon logs
tail -f ~/Library/Logs/hscc-daemon.log

# Check gateway
curl http://localhost:18789/health
```

## Security

- SSH keys managed locally (not in repo)
- Config files git-ignored
- No secrets in codebase
- StrictHostKeyChecking enabled by default
- Model sync via rsync over SSH
