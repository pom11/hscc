## Gate mechanics (what the fix cards face)

- `scripts/tests/test_cli_help_surface.py` runs in the canonical suite
  (scripts leg, ~30 s). Green today = all 312 findings matched 1:1 by
  `cli_help_expected.json` rules.
- Fix a violation → its rule goes STALE → suite FAILS until the card prunes
  the rule (that's the contract; prune, don't suppress).
- Introduce any new violation (or a new instance of a known one) → suite
  FAILS with `NEW`/`EXTRA` naming command + offending text.
- Surface floors (150 paths / 180 probes / 60 examples) fail the suite if a
  refactor shrinks the audited surface without amending the audit.
- The audit NEVER executes mutating verbs (sandbox HOME, recording PATH
  canaries for sparkrun/hermes/gh/git, LaunchAgent + api-port tripwires, and
  `api start --help` statically reported, never run). Examples are parse-only.
