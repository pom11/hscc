# Audit note — t_1b206473: theme archive/hygiene/incident/reconcile CLI output (flightdeck Rich epic, card 3/21, group C sub-e)

## What changed

Converted the human-facing output of `flightdeck/commands/archive.py`
(`archive-sessions`), `hygiene.py` (`cmd_hygiene` plan render + clean status),
`incident.py` (`cmd_incident` entry render), and `reconcile.py` (`cmd_reconcile`
plan render) from bare `print(...)` to the flightdeck themed Rich layer via the
shared helper `hscc-project/flightdeck/commands/_theme.py` (guarded lazy import
of `hscc_daemon.cli_theme`). NO second theme layer was created; all four files
route through `_theme.make_console` / `panel` / `status_panel` / `escape`.
`escape()` is applied to every user/body-derived line (titles, worktree paths,
branch names, project names, thread ids, reasons) so literal Rich markup
renders literally. Errors and the dry-run/applied notices stay plain
`print(..., file=sys.stderr)` — deliberately NOT themed, matching every prior
card.

Line-looping human renders follow the established rule: accumulate lines into a
list, then print ONE panel (`make_console().print(panel(title, "\n".join(lines)))`).

1. `--json` output byte-identical to pre-conversion.
   - No `print(json.dumps(...))` line changed in any of the four files

     incident.py has no `--json` mode). Confirmed via `git diff` grep: the
     combined diff's `json.dumps` lines are all context (unchanged).
   - Terminal proof (docs/audits/t_1b206473_verify_e2e.py, real piped
     subprocess): `archive-sessions --json` output byte-equals the canonical
     `json.dumps({...}, indent=2) + "\n"`, valid JSON, `rc: 0`, no ANSI.
2. Non-TTY piped output has NO ANSI (`\x1b`). Proven for every converted
   command in BOTH the pytest no-ANSI regression classes AND the
   real-subprocess e2e script (`archive-sessions` human + `--json`).
3. Stderr error paths stay plain `print(..., file=sys.stderr)` (matching every
   prior card: errors deliberately left out of the themed layer).
4. Rich-markup pitfall fixed: literal `[PRUNE]` / `[KEEP]` markers and any
   user text are escaped so they render literally. Board slugs, card ids,
   titles, worktree paths, branches and reasons all pass through `escape()`.
