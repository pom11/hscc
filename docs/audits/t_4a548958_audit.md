Converted the human-facing output of `flightdeck/commands/review.py` (card
review `cmd_review`, awaiting-review `cmd_queue`, verify+gate `cmd_verify`,
watermark), `roadmap.py` (`show`, `progress`, `add`, `move`, `done`, `adopt`),

renders literally. Errors stay plain `print(..., file=sys.stderr)`.

as-is: it is an interactive TTY re-render loop that already emits raw ANSI
(`_clear`) and is not a static "human-facing rich render" — matching exactly
how group B left qa.py's `--watch` lone (see t_b2d2c0ae_audit.md). Only the
one-shot `cmd_standup` human path routes the pre-rendered digest string through
a themed panel (content preserved, escaped).
