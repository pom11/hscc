All three ship as single-size 1024px AppIcon sets (Xcode 15+ format): one 1024 PNG per appearance (light/dark/tinted) generated from these SVGs — iOS scales every required size. Wired via ASSETCATALOG_COMPILER_APPICON_NAME in project.yml, same source used for widget/Live-Activity glyphs.
Reading the shots. 1–2: home dock (Chat · Fleet · Cluster · Approvals · Settings) and the drawer reached by edge-swipe or the top-left button; the drawer groups are Work / Cluster / Knowledge / App and every existing screen lives there — nothing is dropped (migration map: spec §8). 3–4: the chat is edge-to-edge — no list chrome, no cards around rows; your messages are the only filled bubbles, the REPL's replies are plain text; reasoning and tool calls are compact hairline rows that expand in place; the connection state is the 9pt dot in the nav bar (VoiceOver: “Live — connected, receiving”), and turn state is the small pill that only exists while a turn runs. 5–6: home + drawer in light. 7–8: one list recipe everywhere (leading status dot, title over mono caption, trailing chip). 9: app-icon candidates at real 60pt + 29pt sizes with tinted variants.

Rules the mockup follows: 44pt minimum hit targets (icon buttons are 44×44 even when the glyph is 22); semantic colour roles only (mint/amber/muted-red, light-remapped values ≥4.5:1); Dynamic Type respected (rows grow, composer caps at xLarge); no destructive action without confirm; primary action is always top-right or the circular send, never floating mid-screen.
