# t_87663869 — GAP-B-4: dep_pr / escalate cron watchers have no staleness/doctor detector

Status: IN PROGRESS (design settled, implementation starting).

## Task restatement
The two Hermes-cron watchers (`scripts/dep_pr_watcher.py` daily, `scripts/escalate_watcher_run.py`
*/15) die silently — nothing in HSCC notices. Make each observable the same way daemon streams
are: a stamp on every pass + a doctor row that warns (non-fatal) when the stamp is older than a
bounded window (>= 3x cadence) and says "not configured" cleanly when the watcher is off.

Constraints: reuse `hscc_daemon/state.py` write_state stamps + the existing doctor/verify check
pattern; no second heartbeat format; do NOT move the watchers into the daemon; commit early;
open a PR; never merge.

## Design decisions (mine, this card)
- Stamp: each watcher calls the existing `hscc_daemon.state.write_state()` on EVERY pass (including
  idle passes — the stamp must advance when there is nothing to do, else "idle" is
  indistinguishable from "dead"). Streams: `dep_pr_watcher`, `escalate_watcher`.
- Cadence SOT: one table in `hscc_daemon/cron_watchers.py` (dep 86400s, escalate 900s, matching the
  installer defaults), stale window = 3x cadence.
- Doctor row: `hscc-bootstrap/doctor_cron_watchers.py` (stdlib-only, so preflight never needs the
  runtime package) + wired into `run_doctor()`.
- `hscc verify` interaction: the stamps live in `~/.hscc/state/` so `check_daemon_streams` would see
  them — it must not cry wolf on the daily watcher with its flat 600s window, and a dead watcher
  must not turn verify RED (card says warn/non-fatal). Handled explicitly; see implementation.

## Findings (file:line at origin/main 66c40bbe)
- `scripts/dep_pr_watcher.py:184-197` `main()` returns 0 early when no PRs — no trace of a pass.
- `scripts/escalate_watcher_run.py:101-146` `main()` prints/notifies only when there are lines.
- `hscc_daemon/state.py:80-116` `write_state(stream, data)` = canonical stamp format
  (`timestamp` + `stream` + payload), atomic tmp+replace, honours `persist_disabled()`.
- `hscc_daemon/verify.py:251-376` `check_daemon_streams` reads every `~/.hscc/state/*.json`,
  per-stream window `max(max_age_s, 2*interval + 90)` from `daemon_ops.PERIODIC_INTERVALS`;
  `ok is False` ⇒ RED, `ok is None` ⇒ UNVERIFIED (verify.py:1567-1575).
- `hscc_daemon/verify.py:456-458` repo warn convention: WARN = `ok: True` + `WARN:`-prefixed detail.
