## Task restatement
The two Hermes-cron watchers (`scripts/dep_pr_watcher.py` daily, `scripts/escalate_watcher_run.py`
*/15) die silently — nothing in HSCC notices. Make each observable the same way daemon streams
are: a stamp on every pass + a doctor row that warns (non-fatal) when the stamp is older than a
bounded window (>= 3x cadence) and says "not configured" cleanly when the watcher is off.

Constraints: reuse `hscc_daemon/state.py` write_state stamps + the existing doctor/verify check
pattern; no second heartbeat format; do NOT move the watchers into the daemon; commit early;
open a PR; never merge.

## Design decisions (mine, this card)
- Stamp: each watcher stamps on EVERY pass through the canonical `hscc_daemon.state.write_state()`
  (idle passes included — the stamp must advance when there is nothing to do, else "idle" is
  indistinguishable from "dead"). Streams: `dep_pr_watcher`, `escalate_watcher`.
- SOT module: `hscc_daemon/cron_watchers.py` — cadence table (dep 86400s, escalate 900s, matching
  installer defaults), stale window = 3x cadence, `stamp()` / `stamp_failure()` / `read_stamp()` /
  `verdict()`. One file, imported by both sides. (An earlier stdlib-only mirror under
  hscc-bootstrap/ was deleted in favour of doctor.py's thin bridge — a second copy of the stamp
  format is exactly what the card forbids.)
- Doctor row: `doctor.py` bridge (`_load_cron_watchers` + `_check_cron_watchers_row`) wired into
  `run_doctor()`; stdlib fallback keeps preflight working without the runtime package.
  WARN (ok=True + `WARN:` detail), never fatal — doctor is Stage 1 and the daemon may legitimately
  predate the feature.
- Crash visibility: the `__main__` blocks call `run_with_failure_stamp()` — an exception stamps
  `ok=False` then re-raises, so "cron fired and the script raised" is distinguishable from
  "cron never fired" (stale) and from a healthy idle pass.
- Stamp plumbing must never cost the watcher its real work: `_stamp_module()` is defensive,
  `_stamp_pass()` never raises; a missing/broken stamp module warns on stderr (the cron run record).
- `hscc verify` interaction: `check_daemon_streams` must not claim these stamps — verify's flat
  window would cry wolf on a daily watcher, and verify is gate-critical (RED blocks) while this
  card says warn/non-fatal. verify.py excludes both streams explicitly and names them in its
  detail; liveness for them belongs to doctor.
- Install-time stamp: each installer writes a `source: "install"` stamp so a freshly installed
  watcher reads "ok" at once instead of "stale" for 3 cadences (doctor's not-configured branch
  reads absence, not freshness — the install stamp must not fake a real pass).
