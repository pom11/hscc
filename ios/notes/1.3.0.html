HSCC apps 1.3.0

Added

  • Needs me widget: what is waiting on you, from hscc notify list.
  • Merge Queue widget (iOS, Lock Screen, macOS) and a merge-queue section in the menu bar.
  • Cluster Graph widget: Swift Charts over /v1/cluster/history at every size, plus a small sparkline and a GRAPHS section in the macOS dropdown.

Changed

  • One history source for every widget (/v1/cluster/history); /v1/metrics/history is retired.
  • Monitor tables match the CLI view-model; Cluster Lock Screen note has one source.
  • Each widget is registered from one manifest file.

Removed

  • App notifications (APNs registration and alerts). Use the Needs me widget.
