Before you install

  1. Your device must be registered by the maintainer. This is an Ad Hoc build: Apple only allows the iPhones listed in its provisioning profile. To find your UDID, connect the iPhone to a Mac, open Finder, select the iPhone, and click the line that shows its model and capacity until the UDID appears (Apple Configurator shows it too). Send that UDID to the maintainer, who adds it at developer.apple.com → Devices and re-runs the release. Get your device ID registered.

Install

  1. Open https://pom11.github.io/hscc/ios/ in Safari on the iPhone.
  2. Tap Install HSCC above, then confirm Install in the dialog.
  3. Settings → General → VPN & Device Management is not needed for an Ad Hoc build. Only if iOS explicitly asks you to trust the developer, trust it there.
  4. Open HSCC, add your cluster (the addresses and token), then add widgets (long-press the Home Screen or Lock Screen → +) and start any Live Activities you want.
  5. To update, open this page again and tap Install HSCC. The new build replaces the old one and keeps your settings.

Troubleshooting

“Unable to install HSCC” — this iPhone is not in the provisioning profile. Send the maintainer its UDID (step 0), then re-run the release and install again.

Nothing happens when I tap Install — the page is not open in Safari, or it is not being served over HTTPS. Copy the link into Safari.

It installs but widgets or Live Activities cannot see my cluster — make sure the app itself is configured first, then re-add the widget from the gallery.

Get your device ID registered

Ad Hoc installs are limited to devices the maintainer has registered with Apple. You only need to do this once per iPhone.

Finder: connect the iPhone → select it in the sidebar → click the model/capacity line until the UDID is shown → right-click to copy it.

Apple Configurator: select the device → the UDID is in the device details.

Send the UDID to the maintainer. They add it at developer.apple.com → Devices, then re-run ios-app/scripts/release_adhoc.sh <version> so the new profile includes it.
