- **`scripts/tests/test_cli_help_surface.py::test_a_table_identical_under_sibling_interpreters`
  was not flaky, it was over budget — and the budget was being spent on work
  that is thrown away.** Measured on this host (14 cores) with 8 CPU spinners
  plus 8 concurrent short-interpreter launches (the shape several pytest legs
  produce), the gate's own sibling command
  `python scripts/hscc_cli_help_audit.py --repo <repo> --a-table ''` took
  **312.55 s** against the test's `timeout=300` — the card's
  `subprocess.TimeoutExpired … timed out after 300 seconds`, reproduced on the
  first loaded run with no diff applied. Root cause, counted rather than
  guessed: `a_table()` walked all **169** surface paths / **331** invocations
  and rendered each at **every** width — 3 for `flag`/`flag2`, 2 for `help` —
  i.e. **899 distinct `(argv, width)` CLI subprocess launches**. But it reads
  only `a_findings_for_surface(renders)`' `kind == "A"` entries, and those come
  from `max(renders)` *alone* (that function's own rule 1); the 80 and 120
  renders exist only to feed the `A-WIDTH` guard, which `a_table` discards on
  the next line. So **600 of 899 interpreter launches produced bytes that were
  parsed and thrown away**, and they were the difference between 300 s and
  green. `a_table` now probes each surface at its one authoritative width
  (`A_TABLE_WIDTHS`: 500 for `flag`/`flag2`, 120 for `help`) — **899 launches
  → 331**, a 2.7× cut with a **provably** unchanged table, because the deleted
  renders could only ever have contributed the `A-WIDTH` branch that this
  function never reads. The full audit is untouched: (B) still measures 80 and
  120, and the `A-WIDTH` guard still runs there.
- **Why `--a-table ''` was walking the whole surface at all (the second half of
  the cost, and it is by design — now a stated design).** `scripts/tests/cli_help_a_counts.json`
  ships `{"counts": {}, "lines": {}}`: the green state is **zero** (A)
  violations, so `surfaces = sorted(report["a_counts"])` is `[]`, which the
  gate passed as `--a-table ''`, which `main()` turned into `want = None` —
  "walk everything". Reading the code alone that looks like an accidental
  empty-list-means-all bug, and "fixing" it to walk nothing would have made the
  cross-interpreter pin assert `{} == {}` having executed zero probes: a test
  that can only pass. The strong reading is the correct one — with no local
  leak, the sibling's job is to prove it sees no leak **either**, on the whole
  surface — so the full walk stays, is now affordable, and is no longer
  accidental: the gate passes `--a-table '*'` explicitly, the argv in a future
  `TimeoutExpired` reads `'*'` instead of `''`, and the docstring says in
  words that an empty local table means "sibling must independently find
  nothing", not "nothing to check".
