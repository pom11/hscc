- **`hscc doctor` can now SEE a stale sparkrun reservation — and release it
  only when the operator says so.** A killed sparkrun client leaves a
  reservation row in sparkrun's operations ledger whose owner pid is dead;
  the next launch or proxy start then fails "Execution resources are busy or
  require reconciliation after an interrupted operation" — this is what
  blocked the .244 orchestrator launch during the template switch, and
  nothing in hscc could see the row, so a stale claim read as real
  contention. New row `sparkrun reservations (stale execution claims)`
  reports every dead-owner claim NAMED, with its resource, pid and NODE
  (WARN, never fatal — a stale row blocks a launch, it does not condemn an
  install). `doctor --fix` is the release half and the ONLY path that
  deletes: one `reconcile_reservation` call per dead owner. An unanswered
  probe is an ERROR and its node is never touched — a false-empty would
  clear the way for a launch that then fails.

  Both rules the card set are held. **Liveness is a fleet fact**: the probe
  ships to the node and runs there under the node's own sparkrun venv
  python (resolved from the node's `sparkrun` CLI shebang, the
  `_SPARKRUN_STATUS_SCRIPT` shape), over the sanctioned
  `clusterlib.ssh_cmd -> sparkrun_bridge` door — never local, never
  hand-rolled ssh; a local pid probe is false-empty on this fleet. **The
  ledger is sparkrun's**: the remote python names only
  `sparkrun.core.coordination.reservations` (returns `{owner, resource,
  process, alive}` — the node judging its own processes via
  `process_identity.alive`) and `reconcile_reservation(…,
  acknowledge_effects=True)`, which re-checks liveness inside its own
  `BEGIN IMMEDIATE` and refuses a live owner. hscc never opens
  `operations.sqlite3`, never greps it, and the probe payload is asserted
  free of SQL by test. Production transport REFUSES to exist inside a
  pytest process (the `_default_ssh_factory` fence, shared
  `doctor_rows.under_pytest` marker); every test injects a host-keyed
  fake — 29 cases, 0 sockets, 0 real sparkrun imports.
