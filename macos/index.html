HSCC Widgets

Version 1.4.0 (build 5)

Install with Homebrew

brew install --cask pom11/hscc/hscc-widgets

The app updates itself with Sparkle; Homebrew installs and upgrades the signed, notarized bundle. New releases appear in the update feed.

What's new

HSCC apps 1.4.0

Changed

  • Five widgets, Native look. Cluster (health line, replaces Monitor and Cluster Graph), Boards (stacked bars, replaces Kanban Monitor, Board Status and Projects), Running (longest card), Needs Me (calm when clear), Merge Queue (pipeline). System colors, color only for state. Placed Cluster and Boards widgets keep working.
  • Lock Screen gauges for all five widgets (circular, rectangular, inline).
  • One Live Activity: Cluster watch. Wake, Monitor, Running Cards and Board Progress activities are removed.
  • Honest data age. Every widget shows when its data was taken; stale data is dimmed with "stale · HH:mm", a failed fetch shows "offline · HH:mm", and Needs Me never says "All clear" unless the fetch succeeded.
  • Refresh that actually happens. Cadences fit WidgetKit's daily budget (15 min, Running 10/30, Merge Queue 5/30); the app reloads widgets on open and after a fetch. Settings now drive these values.

Added

  • CarPlay screen (rows with gauges): cluster node gauges, boards, running, needs you, merge queue on one screen, refreshed every 30 s. Simulator only for now: Apple has not granted HSCC a CarPlay entitlement, so device builds are unchanged.

Fixed

  • Live Activity refresh "Off" no longer polls every minute.
  • The Fleet screen shows the server's health-check age instead of implying a fresh check.
  • The widget network session is shared, so the API no longer runs out of connections.
