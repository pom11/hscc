HSCC Widgets

Version 1.4.1 (build 6)

Install with Homebrew

brew install --cask pom11/hscc/hscc-widgets

The app updates itself with Sparkle; Homebrew installs and upgrades the signed, notarized bundle. New releases appear in the update feed.

What's new

HSCC apps 1.4.1

Fixed

  • Widgets now match the approved design. Every widget sits on a solid card (white in light mode, near-black in dark) instead of a see-through grey, on iPhone and Mac.
  • Cluster names nodes S1–S4 so they fit the medium widget and the Lock Screen gauge.
  • An idle cluster reads 0 tok/s instead of a dash.
  • Merge Queue small widget uses the designed PR number size.

Requirements

  • macOS 14 (Sonoma) or later on Apple silicon or Intel.
  • The HSCC menu bar app and desktop widgets share the same App Group as the iPhone app, so clusters you saved there are already available.
